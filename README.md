# One Word, First Thought

The first word that comes to mind (7 characters): a Welsh word for a deep
longing for a home that no longer exists, or never was — hiraeth.

> hiraeth

## Files

- `entry.txt` — the word, written by `main.ts` (not stored in the repo)
- `main.ts` — writes the entry word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
  (or `/output/entry.txt`), validating it is exactly one word and
  1–24 Unicode code points, then reads it back and verifies it
- `LICENSE` — MIT

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
